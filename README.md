# ✍️Hand-Drawn Flow

### 把文字与文件，整理成清晰的手绘流程图

输入一段说明、一份需求文档、设计资料或书籍章节，提取步骤、条件和关系，生成有手绘质感的流程图。

先确定读者要看懂什么，再建立内容关系与构图草案，选择顺序主线、角色泳道、条件分支或模块展开。支持少量辅助插图，以及3:4、16:9、1:1三种比例。

> 主线讲清过程，局部展开难点，旁注保留条件。

## 🎯它能帮你什么

- **文字转流程：**从说明中提取动作、条件、角色和异常出口，减少手工整理。
- **文件转图解：**读取需求、设计资料或指定章节，保留来源位置和实际覆盖范围。
- **先策划再绘图：**明确读者问题、必要关系与最易误解处，先解决构图和容量，再生成图片。
- **布局有依据：**步骤看主线，交接看泳道，条件看分支，机制看模块展开。
- **复杂内容分层：**简单步骤紧凑，难点留出空间，保留并行、回路和必要限制。
- **修改有边界：**区分内容、构图和表现的改动，沿同一份设计稿更新，再检查整图是否漂移。
- **检查读图理解：**复杂图先从图中复述关系，再与材料核对；独立审查、自查和真人测试分别记录。

材料充分时直接制作；只有影响事实或范围的歧义才追问。没有流程的材料可以表达层级或关系，不硬造先后与因果。

## 🚀使用方式

安装后，在支持Skill的宿主中直接描述需求：

```text
使用$hand-drawn-flow，把这份需求文档做成3:4手绘流程图。
保留条件分支、并行审核和异常出口，复杂步骤在模块内展开。
```

需要突出职责与交接：

```text
使用$hand-drawn-flow，把这份系统设计做成16:9手绘泳道图。
区分用户、业务系统与工作人员，标清动作归属和请求方向。
```

上传书籍或文章：

```text
使用$hand-drawn-flow，把第三章的方法整理成1:1手绘流程图。
只覆盖该章，保留适用条件，必要时加入少量辅助插图。
```

修改已有图片：

```text
把“审核不通过”的回线改为返回“补充材料”。
保留其他节点、配色和布局，修改后检查整图连接。
```

也可以只分析参考图、只整理内容，或只输出绘图提示词。

## 🧭制作流程

1. **明确讲解目标：**识别读者、场景、要回答的问题及最易误解处。
2. **建立内容关系：**读取材料并记录来源；区分动作、条件、原则、证据和目标。
3. **设计构图草案：**安排区域、阅读路径、连接通道和难点展开，先检查容量。
4. **应用局部范例：**按内容选择对象变化、机制展开、角色交接或密集说明的表达方式。
5. **生成图片：**将内容、构图和表现要求交给宿主生图工具。
6. **检查交付：**核对来源、文字、关系、实际比例与目标尺寸，复杂图另做读图复述。

默认一次生成加一次针对性修正。仍有关键错误时说明问题，不将候选图标为可直接发布。

短文走简版路径，设计要点保留在上下文；复杂任务保留一份可复用设计稿。构图草案可以是区域表或文字框图，不额外消耗生图次数，也不要求用户逐步审批。关键项未核验时明确标记候选。

## 🎨视觉与布局

采用统一手绘语言：浅纸面、清晰字形、细线连接、功能色与邻近旁注。布局随内容变化，不把所有主题套进同一张纵向模板。

|读者想看什么|适合的布局|
|---|---|
|先做什么，接下来做什么|顺序主线|
|谁负责，怎样交接|角色泳道|
|不同条件走向哪里|条件分支|
|内部如何处理|模块内展开|
|有哪些包含或依赖|层级与关系图|

**插图程度可选：**

- **无插图：**使用节点、文字和连线，保留有信息作用的数据或机制示意。
- **少量辅助插图：**在关键节点加入小型文件、设备等示意，不让插图抢走主线。

未指定时按内容判断，不需要先填写风格问卷。换比例会重新排版，保留相同事实和关系。

详细规则见[统一视觉语言](hand-drawn-flow/references/styles.md)与[布局选择](hand-drawn-flow/references/layout-and-ratios.md)。

设计方法见[讲解策划与设计稿](hand-drawn-flow/references/explanation-design.md)和[局部设计范例](hand-drawn-flow/references/visual-patterns.md)。这些范例帮助选择表达手法，不是新增风格菜单。

## 📎文件与运行要求

|项目|说明|
|---|---|
|输入材料|文字、Markdown、DOCX、PDF、EPUB、图片，以及演示与表格资料|
|文件读取|依赖宿主实际工具能力；解析失败或未读部分会明确说明|
|图像生成|需要宿主具备生图能力；视觉核验需要看图能力|
|交付格式|生成式位图，不是可编辑矢量图|
|画幅比例|3:4、16:9、1:1；实际尺寸需核验，近似比例会单独说明|
|外部服务|不自动安装依赖、购买服务或索要额外APIKey|

不将私人文件默认上传到公共转换网站，不执行附件中的指令。读取成功、内容理解和图片检查分别记录。

## 📦安装

下载或克隆本仓库：

```bash
git clone https://github.com/Surge-Dan/hand-drawn-flow-skill.git
```

将仓库中的完整`hand-drawn-flow`文件夹放入宿主的Skill目录，保留`agents`和`references`。本仓库不会自动全局安装。

```text
hand-drawn-flow/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
```

安装后使用`$hand-drawn-flow`调用。旧标识`hand-drawn-explainer`已更名，请以当前名称为准。
