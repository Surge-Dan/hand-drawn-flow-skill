# 手绘知识图解 · hand-drawn-explainer

把主题、文章、业务步骤或参考图整理成有手绘质感的知识图解。交付位图；不提供可编辑矢量图。

## 使用

将 `hand-drawn-explainer` 文件夹完整放入宿主的 Skill 目录，保留 `agents` 和 `references`。当前项目只提供源文件和安装包，尚未自动安装到全局目录。

示例请求：

> 使用 $hand-drawn-explainer，把下面的材料画成3:4课堂板书风图解。只使用我提供的事实，突出关键变化和可选路径。

> 使用 $hand-drawn-explainer，将这个申请流程做成16:9工程手记风。主管与财务并行审核，两者都通过才能继续。

> 使用 $hand-drawn-explainer，把这两个方法做成1:1编辑部图解，按相同维度比较，不把比较画成执行流程。

也支持“只分析这张参考图”“只给绘图提示词”“按原风格修改某个节点”。未指定时采用中文、3:4、单张，并按内容推荐风格。

## 依赖与边界

- 正常出图需要宿主具备图像生成能力，视觉检查需要看图能力。
- 优先使用已有原生工具，不要求额外 Key，不自动安装或购买服务。
- 精确尺寸依赖实际生成结果，须读元数据核验；换比例会重排信息。
- 纯生图不能保证文字和连接一次全对，默认检查后集中修正一次。
- 保留输入内容和最终提示词，方便追溯；局部改图后仍检查关键内容。
