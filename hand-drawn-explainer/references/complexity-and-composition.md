# 复杂度与版面

## 先诊断，不按节点数量机械评分

复杂度来自四类压力：文字长度与精确性、关系分支与回路、角色与层级、阅读尺寸与单张限制。六个节点可能比二十个节点更难；不要用数量阈值决定能否完成。

| 压力 | 设计动作 | 不可采用的捷径 |
| --- | --- | --- |
| 长文本 | 动作短标签配邻近说明；保留精确文本区 | 擅自删条件、缩写改变含义 |
| 多角色 | 泳道或责任带；交接对象跨边界 | 一人一种颜色但不显示交接 |
| 并行与判断 | 独立分流、汇合、判断；标出全部/任一 | 将并行改成顺序 |
| 多条回路 | 外侧独立通道、明确起终点；必要时用成对带方向的续接标签 | 长线穿过正文、只写“返回”不连接 |
| 系统层级 | 总体轮廓加一个局部展开，界面与内部机制分开 | 多层嵌套挤出小字 |
| 多维比较 | 相同维度对齐，突出差别 | 用流程箭头表示优劣 |
| 精确数字/公式 | 专门可核对的公式或数据区域 | 伪图表、装饰性公式 |

## 布局前的三项决定

1. **主线**：读者最终回答什么，阅读从哪开始、到哪结束。开放关系图可以没有执行终点，但必须有入口和导航规则。
2. **对象**：有变化过程时追踪一个对象，用稳定名称和标识显示其状态；没有过程就不强加故事。
3. **难点**：只选最需要展开的关键关系作为视觉中心；多个同等复杂难点则考虑分面或组图。

先写区域与连接计划，再写绘图指令。例：“左侧输入，中央并行双审核，右侧结果；拒绝回路走下缘；证据引线走模块内部。”这不是固定模板，下一张允许完全不同构图。

## 容量处理顺序

删重复解释与装饰 → 相同对象复用标识 → 主次分层 → 难点局部展开 → 重排区域与走线 → 仍无法在目标尺寸阅读时协商更大载体或拆图。

单张不等于每项同等突出。可以保留全部必要信息，同时将补充说明降为次级文字；但关键条件、否定词、单位和出口不能降到不可读。

“总览＋细节”须经用户允许，或用户已授权自动拆分。总览保留完整主关系，细节图注明对应节点；不得把一个必要异常路径藏在没有入口的附图中。

## 关系压力测试

在出图前用文字走一遍正常路径、每个异常出口、每条回路、每个并行汇合。区分“任一通过”和“全部通过”；返回上游后哪些步骤重做必须依据材料。

在出图后沿真实可见线条重走，不接受仅由文字标签推断正确。若⑤写“返回④”但箭头实际指向旁注框，即为失败。若删除误线同时删了正常路径，也为失败。

## 可迁移的视觉签名

每张至少有一个由内容产生的讲解动作：同一对象的状态变化、关键机制剖解、来源到结论的对应、并行关系的汇合、同维度差异对照。选择适用者即可；不凑数量。

去掉纸纹和手写字体之后，图仍应能解释关系。否则这张图的设计还停留在装饰层。
