# 手绘知识图解

把内容讲明白，再让笔触有性格。读者应看出对象是什么、发生了什么变化、关系为什么成立。默认交付实际图片，不用一段提示词冒充成品。

优先级：事实与关系 → 阅读清楚 → 主题适配 → 手绘质感 → 视觉新意。丰富与克制都可以成立；密度由内容决定，不用纸纹或空白假装设计。

## 1. 确认任务，不重复访谈

先从现有请求提取：读者、核心问题、输入角色、用途、比例、风格和输出模式。只询问会改变解释范围或事实含义的缺口。用户已要求制作且材料充分时，简述选择后执行，不额外设置审批环节。

默认：中文、3:4、单张、自动选风格；用户指定优先。支持3:4、16:9、1:1。未指定风格时依据内容选择，不每次发风格问卷。

| 请求 | 路径 |
| --- | --- |
| 完整材料转图 | 整理材料，建立关系，直接设计 |
| 仅给主题 | 明确核心问题；必要时核实知识；关键范围有歧义才问 |
| 参考图＋新内容 | 看图后区分内容来源、风格参考、改绘对象、补充素材 |
| 修改现有图 | 列出修改项与保留项，只改相关内容；成品仍需检查漂移 |
| 仅分析／仅提示词 | 完成相应中间产物即停止，不生成图片 |
| 要可编辑图 | 说明本 Skill 输出位图，按用户所需交付转交合适能力，不假装可编辑 |

检查本次宿主是否具备看图和生图能力。缺少生图能力时给出内容骨架与完整绘图指令，明确图片未完成，不安装工具或切换付费服务。

## 2. 锁定内容与关系

建立简短内部底稿：必须出现的内容、允许压缩的解释、事实出处、示例标识、未解决疑点。数字、单位、公式、专名与条件逐项保留。资料冲突、仅主题、专业知识或需要补充事实时读 [内容与可信度](references/content-and-trust.md)。

将内容转成关系稿；按 [图解语法](references/diagram-grammar.md) 选择顺序、条件、并行、循环、包含、比较或注释。给关键节点和连接临时编号，供核对使用，编号不进入成品，除非它本身是读者需要的步骤序号。

同一份图里区分“下一步”“数据流向”“解释引线”；不能因为要画流程图就虚构因果、顺序或循环。

## 3. 决定怎么讲

选一个主结构，必要时加一种局部辅助结构。问自己：读者最容易卡在哪里？把最大的解释空间给这个位置，简单步骤保持短。

适合时用一个具体对象贯穿过程，显示每步输入和输出的变化。对象的名称、颜色和画法跨步骤一致。分类、对比等不适合故事的内容，不强行添加角色与情节。

每个可视元素必须有用途：表达对象、变化、条件、数量、分组或提醒。删除无用途的图标和重复边框。图形能解释的关系，不再叠一段同义长文字。

按 [布局与比例](references/layout-and-ratios.md) 编排实际画面。换比例需要重排，不能裁切或拉伸。装不下时优先压缩重复解释；仍过密则提出拆分，用户未允许时不擅自从一张变成组图。

## 4. 选择手绘语言

读 [风格系统](references/styles.md)，选课堂板书、工程手记或编辑部图解。用户有参考图时，再读 [参考图分析](references/reference-analysis.md)，参考可覆盖预设，不强行拉回默认风格。

确定具体的笔触、字形、颜色角色、分组方式、强调方式和密度。保持统一，但不把所有主题画成相同方框。

使用参考图的视觉关系，排除仅属于该样本的作者署名、内容、品牌和布局。原图含有多少步骤，不是新图应该有多少步骤的依据。

## 5. 生成实际图片

按 [绘图指令](references/prompt-compiler.md) 把底稿、关系与设计编成可执行要求。用明确文本和具体画面关系，避免堆砌“高级、精致、有设计感”。

生成或编辑时读 [工具适配](references/rendering.md)，使用宿主实际可用的图像能力。需要参考图片时传入实际图片，并标明角色。只分析图片不代表已经将它提供给生成工具。

复杂任务可先用两三句说明结构、风格和比例；不要把整份内部底稿展示成用户必须逐项批准的清单。

需要保存文件时放在本次任务目录；不覆盖原图、不写入 Skill 安装目录。保留内容稿与最终绘图指令，便于复核或再次生成；临时调用可保留在工作上下文，无需为每张图创建一堆文档。

## 6. 看过成品再交付

读 [检查与恢复](references/quality-and-recovery.md)，对照内容底稿与关系稿检查实际图片。检查全图、关键细节和目标阅读尺寸，不能用“生成成功”代替“检查通过”。

默认一次生成加一次针对明确问题的修正。第二次仍有关键错误，保留候选、指出问题并给出具体取舍，不标为可直接发布，也不自行无限重绘。用户另有迭代要求时跟随用户。

默认回复：图片＋一行风格／实际比例；有外部事实时补必要出处，有未解决限制时明确说明。详细提示词、内容稿和设计推导仅按需展示。无图输出明确写“分析”或“提示词”，不声称已完成生图。
