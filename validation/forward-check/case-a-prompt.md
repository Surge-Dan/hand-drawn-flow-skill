# A：16:9 工程手记风提示词

以下仅为绘图提示词，尚未生成图片。

制作一张 16:9 横版中文手绘流程图，采用工程手记风。标题为“申请与并行审核”，标题旁标注“模拟规则”。读者应能看懂：主管审批与财务审核并行，两边都通过才通知员工；任一方退回，员工补充并重新提交后，重走两项审核。

画面从左向右阅读。左侧是“员工提交申请”；中部留出最大的解释空间，上下并列“主管审批”和“财务审核”；右侧是通过条件与通知；底部留出退回与重新提交的回路。

必须准确呈现下列节点与连接：

- “员工提交申请”连接一个分流点，再分别连接上方的“主管审批”和下方的“财务审核”。两条分支同时展开，旁边写“并行”。两项审核之间不连顺序箭头。
- “主管审批”和“财务审核”各引出一条标注“通过”的路径，两条通过路径进入同一个汇合门。汇合门明确写“两边都通过”，再连接“通知员工”。汇合门表达必须同时满足两个通过结果，不能画成任意一条到达就可继续。
- 两项审核还各自引出一条标注“退回”的路径，通向底部同一个“员工补充”节点。在退回路径汇入处写“任一方退回”，明确一方退回即走此回路，不要求两方都退回。
- “员工补充”连接回左侧“员工提交申请”，回程箭头标注“重新提交”。重新提交后仍经同一个分流点进入“主管审批”和“财务审核”，旁注“重走两项审核”。不得让补充后的申请直接到汇合门或“通知员工”，不得只返回退回的那一项审核。

动作节点使用简洁的手绘模块；分流点和汇合门使用清楚的连接结构，与动作模块区分。两条通过路径在中部与右侧的主区域内行进，两条退回路径沿该区域外缘进入底部回路。避免交叉；若必须交叉，清楚区分跨线与实际连接。所有箭头端点明确，条件文字紧邻对应分支，不漂浮在两条线之间。只使用箭头表示流程；解释旁注通过邻近位置或无箭头细引线关联对象。

使用干净浅白纸面，石墨灰针管笔细线组织结构，边框有轻微自然手绘波动。深青标识主路径与通过汇合，琥珀标识退回路径和补充回路，同时保留文字条件，不仅依赖颜色。关键汇合边界略重，让“两边都通过”和“任一方退回”的区别成为视觉重点。标题短而清晰；节点标签与条件采用规整易读的中文字形；手绘感集中于线条和短标题。不给每个节点添加装饰图标。

只表现上述模拟规则。不补充审批时限、审核顺序、自动通过、超时、撤回、驳回终止、补充次数限制，也不规定一方退回后另一方是否取消或继续。不要保留内部节点编号，不添加无依据的数字、公式、伪坐标或工程尺寸标注。
