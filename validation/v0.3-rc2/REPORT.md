## 行为审查（文本推演，非独立模型实测）

| 请求 | 当前应走路径 | 不应出现 |
| --- | --- | --- |
| 未指定风格的需求文档 | 标准流程，保留条件/并行/异常 | 自动选印画海报 |
| 多角色设计文档 | 工程流程或泳道，注释与执行区分 | 装饰电路、假尺寸 |
| 要少量插图 | 关键节点小图，主线完整 | 大幅柜子植物替代流程 |
| 故事卡 | 按证据整理事件时间线或关系 | 自动绘本、虚构结局 |
| 无过程的文章 | 层级/比较/关系，必要时澄清 | 强行添加先后与因果 |
| 要更高级、多彩 | 强化层级与功能色，控制装饰 | 扩展新插画门类 |
| 旧叙事墨绘请求 | 说明当前范围，若仍要插画按独立任务处理 | 静默忽略用户要求 |
| 长文、比例变更 | 记录覆盖、重排相同事实关系 | 假称全读、裁掉步骤 |
