## 真实出图

测试材料为虚构教学案例：[内容和关系稿](sample-01/content.md)。不是用户调研事实或产品实验结果。

- 工具：宿主内置 imagegen；一次新图生成，一次参考原候选的编辑。
- 首图：[candidate-01.png](sample-01/candidate-01.png)。主 Agent 已查看实际输出。
- 发现：红色回路看起来从蓝色“推进”出口起始；遗漏必须显式显示的“把导出放到报表页顶部”。未判为合格。
- 修正：将“调整假设”移动到左侧，使回路线从它出发；“推进”移到右侧并作为终点。补全假设句，移除小报表示意中的柱状图。
- 修正图：[sample-01.png](sample-01/sample-01.png)。主 Agent 已查看实际输出。
- 原始指令与编辑指令均保存在同一目录。

| 核对项 | 修正图结果 |
| --- | --- |
| 原话、问题、假设、预期和任务句 | 可见，含义与底稿一致 |
| 五个阶段及三个观察维度 | 可见，顺序与底稿一致 |

检查边界：主 Agent 看过工具展示的实际全图，进行了文字与关键连接的人工核对；未做自动 OCR、逐像素比对、独立视觉评审或实际手机设备阅读测试。此记录不构成绝对零错误保证。

据样图失败补入：回路须同时检查起点和终点；图形表达不能替代要求显式出现的关键文字。用户尚未评价审美方向。
