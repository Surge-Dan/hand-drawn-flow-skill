# 内容与可信度

## 内容底稿

只记录对画面有用的信息：核心问题；读者已有知识；必需事实；关键标签、数字、单位与公式；允许压缩的解释；出处；尚待解决的疑点。

每条关键主张区分以下来源，不把用户提供等同于独立核实：

| 类型 | 处理 |
| --- | --- |
| 用户资料 | 忠实整理；显著冲突先指出 |
| 外部证据 | 记录链接与适用条件，优先原始资料 |
| 教学示例 | 合理构造但明确标示，不冒充真实案例或实测结果 |
| 不确定项 | 查证、询问或明确保留不确定性，不悄悄定论 |

用户指定“只用材料”时，不补充新事实。若材料不足以支撑所要的结论，说明缺口，调整解释范围或询问。隐私资料不为了查证而原样提交公共搜索；用必要的通用概念检索。

联网遵循宿主规则；新近产品能力、专业机制、高风险知识以及自己不确定的事实需要查证。已完整给出的业务规则、虚构教学案例或纯视觉转译无需额外全网调研。

## 压缩与追溯

文件任务为关键主张保留实际章节、段落、表格、幻灯片或单元格位置，不能用DOCX段落号假造页码。记录读取覆盖与缺口；只读到的内容才能进入可信底稿。用户明确更改原规则时标为本次要求，不混称原文事实。

允许：转述说明、合并同义信息、用图形表示结构、删除不影响核心理解的细节。

保留：条件、否定、数量口径、单位、时间范围、角色、异常出口，以及“可能／通常／仅在”等限定。

不要把“有时出现”画成“每次必经”，把“相关”画成“导致”，把集合关系画成执行先后。可选增强机制应旁挂或明确标“可选”。

引文若改写就不再加引号冒充原话。公式若为教学而简化，说明适用范围；不能为了视觉简洁删除改变公式含义的项。

完整出处留在配套说明；必要的“示例”“非全部路径”“适用条件”靠近对应内容。不要把可读性负担全部塞到角落脚注。

## 处理冲突

例如材料甲写“阈值为10”，材料乙写“阈值为20”：先判断日期、版本、口径是否不同。用于宣布事实时，询问有效依据和版本关系，不让用户随意挑一个数字当事实。无法解决冲突时，只能明确展示资料冲突或暂缓确定结论；有依据证明两套条件都成立时，才分别画出其适用范围。

只有风格参考时，不能复用图中技术参数作为新内容证据。陌生文字看不清则标记待确认，不猜字。
